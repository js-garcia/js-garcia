## Proyectos destacados

### TelecomX – Análisis de churn

Proyecto de análisis de datos orientado a identificar factores asociados a la cancelación de clientes.

**Herramientas utilizadas:** Python, Pandas, visualización de datos y modelos de clasificación.

**Qué incluye:**

- Limpieza y preparación de datos
- Análisis exploratorio
- Visualización de variables relevantes
- Preparación de datos para modelos
- Aplicación de modelos de clasificación
- Evaluación de métricas

---

### Alura Store – Análisis de ventas

Proyecto de análisis comparativo de tiendas para apoyar una decisión de negocio.

**Qué se analizó:**

- Ingresos por tienda
- Categorías de productos
- Calificaciones
- Productos vendidos
- Costos de envío
- Conclusión basada en datos

---

### Tienda online – JavaScript

Proyecto web desarrollado como práctica de JavaScript.

**Funcionalidades:**

- Catálogo de productos
- Carrito de compras
- Filtros
- Búsqueda
- Persistencia con LocalStorage
